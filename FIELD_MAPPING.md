# KSA Visa field mapping (UK applications)

This is a preparation checklist based on the supplied application screenshots. Visa Desk stores these values locally; its website autofill control is still disabled. Check each field against the live form before submitting.

| KSA Visa field | Visa Desk field or asset | Rule |
| --- | --- | --- |
| Nationality | Nationality | British maps to United Kingdom / GBR on the site |
| Number of entries | Number of entries | Multiple is the UK workspace default |
| Choose visa period / Validity | Visa validity, days | 730 is the value shown in the sample |
| Duration of Stay | Visa duration of stay, days | 180 is the value shown in the sample; planned stay is separate |
| Expected date of arrival | Expected arrival date | Applicant-specific; screenshots show different dates |
| Country of residence | Country of residence | United Kingdom is the UK workspace default |
| Nearest Embassy | Nearest Saudi embassy | London is the UK workspace default |
| Countries visited in last five years | Countries visited in last five years | None means leave the site's country selection empty; verify per applicant |
| Transport Mode | Arrival mode | Air maps to By Air |
| Port of entry | Arrival airport | Match the actual port option shown by the site |
| Headshot | Headshot / prepared 35 × 45 photo | Confirm the pairing and upload manually |
| First name / Last Name | Given name(s) / Surname | Copy exactly from passport |
| Gender / Date of Birth | Sex on passport / Date of birth | Copy exactly from passport |
| Marital Status / Religion | Marital status / Religion | Applicant-specific |
| Email address / Phone country code / Phone Number | Contact email / Phone country code / Phone number | Keep `+966` separate from the national number; review before sharing with site |
| Passport image | Passport page | Downloaded copies use `.png` or `.jpeg` with matching image data; site shows PNG or JPEG up to 5 MB |
| Passport Type | Passport type | Ordinary maps to Normal on the site |
| Passport Number | Passport number | Copy exactly from passport |
| Passport Country of Issuance | Passport country of issuance | United Kingdom is the UK workspace default |
| Place of passport issuance | Place of passport issuance | Verify against each passport and site's wording |
| Place of Birth | Place of birth | A city, distinct from country of birth |
| Passport Issue / Expiry Date | Issue date / Expiry date | Copy exactly from passport |
| Residency country / City / Zip code / P.O Box | Country of residence / UK residence city / UK residence postcode / UK residence P.O. box or street address | UK address values are applicant-specific |
| Residence type in Saudi Arabia | Residence type in Saudi Arabia | Applicant-specific; sample shows Other |
| KSA Home Address | Full address | Verify the shared Saudi address |
| Security Questions | Nine Yes/No fields and conditional clarification fields | Must be answered truthfully per applicant; never prefill No |

## Still unmapped or requiring live-site confirmation

- The personal-information input screen and any fields beyond those visible in the screenshots, including later terms, review, and payment screens.
- The site's exact option values for visa validity, duration, port of entry, residence type, and embassy. The screenshots show selections but do not establish every available option.
- Whether the site's “P.O Box” accepts a street address when no P.O. box exists.
- The screenshot review lists “Country of birth” as a city, while the applicant draft has separate place and country of birth. Verify the live form label before mapping that review item.
- No automatic website transfer or document upload is implemented. Manual form entry and visual verification are still required.
