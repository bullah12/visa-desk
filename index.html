Privacy and storage

Applicant records, passport images and headshots are stored in this browser’s IndexedDB on this device. This app has no server API and does not upload documents.

Clearing browser site data can erase these records. Export an encrypted backup after meaningful changes and keep its passphrase separately.

Desktop and phone keep separate records until you deliberately export and import a backup.
